# gup

> Update binaries installed by "go install".
> More information: <https://github.com/nao1215/gup>.

- Check which Go binaries can be updated:

`gup check`

- Update all installed Go binaries to latest binary version and Go compiler version:

`gup update`

- Update all installed Go binaries to latest binary version, ignoring an outdated Go compiler version:

`gup --ignore-go-update`
